# 👑 공주님 옷갈아입히기 (Princess Dress-Up)

고퀄리티 **SVG로 직접 그린** 공주님 드레스업 게임입니다. 외부 이미지·라이브러리 없이 순수 HTML/CSS/JS와 인라인 SVG(그라디언트·보석·반짝이 효과)로만 동작합니다.

## 실행
완전 정적 파일입니다. GitHub Pages 또는 로컬에서 바로 동작합니다.
```bash
python3 -m http.server 8000   # http://localhost:8000
```
> `index.html`을 파일로 바로 열어도 되지만, **이미지 저장(PNG)** 은 서버(또는 GitHub Pages)에서 더 안정적입니다.

## 특징
- **고정 공주 캐릭터** 위에 아이템을 드래그앤드랍으로 자유 배치
- 머리·몸·발 위치에 **착 붙이기(스냅)** — 가까이 놓으면 점선 가이드가 뜨고 딱 정렬
- 아이템 **이동 / 크기 / 회전 / 좌우반전 / 순서 / 삭제**(편집 툴바)
- **랜덤 코디 / 초기화 / PNG 저장**

## 구조
| 파일 | 설명 |
|------|------|
| `index.html` | 레이아웃 |
| `styles.css` | 스타일 |
| `assets.js` | 공주 캐릭터 + 모든 아이템을 그리는 인라인 SVG 정의 |
| `game.js` | 드래그앤드랍·스냅·편집·저장 엔진 |

## 아이템/색상 추가하기
`assets.js` 하단의 빌더 함수를 호출만 하면 됩니다. 예:
```js
gown('체리 볼가운', '#ff9ec6', '#e0466e', '#fff0f6', '#ff5e9e', '#c01e6e');
crown('다이아 티아라', '#ffe9a0', '#d8ab3a', '#bfeaff', '#1f73c0', false);
```
모든 좌표는 캐릭터 좌표계(`viewBox 400×760`)와 앵커(`cx, cy, aw`)로 통일되어 있어 새 아이템도 자동으로 머리/몸/발에 맞춰 스냅됩니다.

## GitHub Pages
`gh-pages` 브랜치를 Settings → Pages 의 소스로 지정하면 배포됩니다.
모든 에셋이 인라인 SVG라 외부 파일 의존이 없어 어떤 경로에서도 동작합니다.
