# 👗 드래그앤드랍 옷갈아입히기

고정된 캐릭터 위에 헤어·옷·모자·안경 등 아이템을 **드래그앤드랍**으로 원하는 위치에 자유롭게 배치하는 옷갈아입히기 게임입니다. 외부 라이브러리·에셋 없이 순수 HTML/CSS/JS와 인라인 SVG로만 동작합니다.

## 실행
`index.html`을 브라우저에서 열면 끝입니다. (별도 빌드/서버 불필요)

## 사용법
- **배치**: 오른쪽 옷장에서 아이템을 끌어 캐릭터 위로 놓기
- **이동**: 배치된 아이템을 다시 끌어서 원하는 위치로
- **편집**: 아이템을 탭하면 위에 편집 툴바 표시
  - ➕/➖ 크기 · ↺/↻ 회전 · ⇄ 좌우반전 · ⬆/⬇ 순서 · 🗑 삭제
- **빠른 삭제**: 아이템 더블탭
- **🎲 랜덤** / **🔄 초기화** / **💾 이미지 저장(PNG)**

## 구조
| 파일 | 설명 |
|------|------|
| `index.html` | 레이아웃 |
| `styles.css` | 스타일 |
| `assets.js` | 베이스 캐릭터 + 카테고리/아이템 SVG 정의 |
| `game.js` | 드래그앤드랍·편집·저장 로직 |

## 아이템 추가하기
`assets.js`의 `CATEGORIES` 배열에 항목을 추가하면 됩니다.
```js
{ id: 'top_new', name: '새 상의', defaultW: 200, svg: wrap(`<path .../>`) }
```
SVG는 `viewBox 0 0 200 200` 좌표계에 그리면 트레이·무대·저장에 모두 그대로 재사용됩니다.
