# 👗 옷갈아입히기 (드래그앤드랍 + 착 붙이기)

업로드된 **APC_assets**(바디·헤어·옷·신발·액세서리 일러스트) 기반의 옷갈아입히기 게임입니다.
고정된 캐릭터 위에 아이템을 **드래그앤드랍**으로 자유롭게 놓을 수 있고, 머리·몸·발 영역 가까이에 놓으면 **자동으로 착 붙어(스냅)** 깔끔하게 정렬됩니다.

## 실행
정적 파일이라 로컬 서버로 여는 것을 권장합니다(이미지 저장 기능 때문).
```bash
cd raeldressup
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
> `index.html`을 파일로 바로 열어도 옷 입히기는 되지만, 일부 브라우저에서 **이미지 저장(PNG)** 이 차단될 수 있어요. 서버로 열면 정상 동작합니다.

## 사용법
- **배치**: 오른쪽 옷장에서 아이템을 끌어 캐릭터 위로 놓기
- **착 붙이기**: 머리·몸·발의 해당 위치 근처에 놓으면 점선 가이드가 뜨고, 놓는 순간 딱 맞게 정렬됨
  (멀리 놓으면 그 자리에 자유 배치 — 상단의 `착 붙이기` 체크 해제 시 항상 자유 배치)
- **이동**: 배치된 아이템을 다시 끌기
- **편집 툴바**(아이템 탭 시 표시)
  - 📌 몸에 맞추기 · ➕➖ 크기 · ↺↻ 회전 · ⇄ 좌우반전 · ⬆⬇ 순서 · 🗑 삭제
- **더블탭**: 빠른 삭제
- **바디 선택**: 상단 썸네일로 4가지 베이스 바디 교체
- **🎲 랜덤 / 🔄 초기화 / 💾 이미지 저장(PNG)**

## 구조
| 파일 | 설명 |
|------|------|
| `index.html` | 레이아웃 |
| `styles.css` | 스타일 |
| `assets.js` | 바디/아이템 메타데이터(파일경로·크기·슬롯 앵커) — `tools/gen_assets.py`로 자동 생성 |
| `game.js` | 드래그앤드랍·스냅·편집·저장 로직 |
| `assets/` | 리사이즈된 일러스트(원본 APC_assets 기반) |
| `tools/gen_assets.py` | 원본 에셋을 리사이즈하고 `assets.js`를 생성하는 스크립트 |

## 슬롯 앵커(착 붙이는 위치)
각 아이템은 `cx, cy`(무대 너비·높이 대비 중심 위치)와 `aw`(무대 너비 대비 폭)를 가집니다.
값은 `tools/gen_assets.py` 안에서 카테고리별로 정의되어 있고, 바디 포즈에 맞춰 튜닝되어 있습니다.
새 아이템을 추가하거나 위치를 바꾸려면 그 스크립트의 앵커 프리셋을 수정한 뒤 다시 실행하면 됩니다.
```bash
python3 tools/gen_assets.py   # 원본 APC_assets 경로 필요
```

## 크레딧
캐릭터/의상 일러스트: 업로드된 **APC_assets** 패키지.
